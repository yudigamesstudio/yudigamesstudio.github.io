# yudigamesstudio.github.io

The YudiGamesStudio website, served by GitHub Pages from `main`. Plain HTML and CSS, no build step.

- `index.html`: the studio's home page, with a card for each tool and game.
- `<product>/index.html`: one page per product, with its images in `<product>/images/` and its manual PDF.

Product images are WebP copies of the store images rendered in each product repo (`Marketing/<Product>/out/`).
